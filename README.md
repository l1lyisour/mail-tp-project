# mail-tp-project

Система автоматической обработки входящих писем для IT-поддержки. Приложение читает письма из папки `inbox/`, классифицирует их по категориям, перемещает их в соответствующие папки внути `processed/`, ведёт лог обработки и формирует итоговую статистику.

## Возможности

- Чтение входящих писем из папки.
- Классификация по категориям: `access`, `aho`, `documents`, `events`, `finance`, `hr`, `security`, `spam`, `technical`, `unknown`.
- Выделение срочных писем по ключевым словам.
- Перемещение писем в папки по результатам классификации.
- Логирование обработки в `run.log`.
- Формирование итогового отчёта по количеству писем в каждой категории.
- Обработка ошибок чтения и неизвестных форматов.

## Структура проекта

```text
MAIL-TP-PROJECT/                    # Корневая папка проекта
|-- inbox/                          # Входящие письма
|-- processed/                      # Папки с уже отсортированными письмами по категориям
|-- system/                         # Основная логика приложения

|   |-- classifier.py               # Класс Classifier: Классификатор писем
|   |-- handler.py                  # Класс MailHandler: Чтение, обработка и перемещение писем
|   |-- mail.py                     # Класс Email: Модель письма
|   |-- stats.py                    # Класс ReportGenerator: Генерация отчёта
|-- tests/                          # Тесты pytest
|   |-- __init__.py                 # 
|   |-- conftest.py                 # Общие фикстуры и вспомогательные настройки для тестов
|   |-- test_classifier.py          # Тесты класса Classifier
|   |-- test_email.py               # Тесты класса Email
|   |-- test_mail_handler.py        # Тесты класса MailHandler
|   |-- test_report_generator.py    # Тесты класса ReportGenerator
|-- .gitignore                      # Список файлов и папок, которые Git не должен отслеживать
|-- main.py                         # Точка входа: запускает обработку писем
|-- README.md                       # Описание проекта, инструкция по запуску и структура репозитория
|-- run.sh                          # Bash-скрипт для запуска приложения
```

## Логика классификации

Классификация реализована на основе ключевых слов в теме и в содержимом письма. Если письмо не подходит ни под одну из категорий, оно попадает в папку `unknown`. Такой подход делает систему устойчивой к новым и нестандартным типам: письма не теряются, а сохраняются для дальнейшего анализа и возможного расширения набора правил.

## Требования

- Pyrhon 3.10+
- Bash или Git Bash (для запуска `run.sh` на Windows)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/l1lyisour/mail-tp-project
cd mail-tp-project
```

### 2. Подготовка входных данных

Поместите письма в папку `inbox/`.

### 3. Запуск

Linux/macOS:

```bash
chmod +x run.sh
./run.sh
```

Windown (Git Bash):

```bash
bash run.sh
```

## Результат работы

После запуска:

- письма будут перемещены из `inbox/` в соответствующие подпапки внутри `processed/`;
- в корне проекта появится или обновится файл `run.log`;
- в консоли будет выведен итоговый отчёт по количеству отсортированных писем.

## Обработка ошибок

Система учитывает несколько граничных случаев:

- файл невозможно прочитать;
- файл имеет неизвестный формат;
- письмо не удалось отнести ни к одной категории

В таких случаях письмо отправляется в `unknown/`, а информация об ошибке записывается в лог.
